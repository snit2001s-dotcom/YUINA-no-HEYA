ファイルをドラッグするだけで、サイトに自動でアップロード＆公開されます🚀

⚙️ はじめての設定（1回だけ）

アップロードには GitHub のアクセストークンが必要です。トークンはこのブラウザの中にだけ保存され、 サイトには公開されません。

トークンのつくりかた
  1. GitHubのトークン作成ページを開く
  2. 「Repository access」で Only select repositories → このサイトのリポジトリ を選ぶ
  3. 「Permissions → Repository permissions → Contents」を Read and write にする
  4. 「Generate token」を押して、表示された github_pat_... を上の欄に貼り付ける
